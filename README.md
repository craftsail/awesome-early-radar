# Awesome Starter GitHub

每天更新的 GitHub 新项目观察：**新建不久、还不太火、但正在涨**的仓库，加上 Show HN、Hugging Face 热门论文和 Lobsters 上值得一看的东西。

每个仓库都标了它现在处在什么位置：

| 标记 | 意思 |
| --- | --- |
| 🟢 窗口内 | 还在加速、HN 上没人发过、没有疑点 |
| 🟡 在降温 | 增速在放缓 |
| 🔵 已被发现 | HN 上已经火过 |
| 💤 不活跃 | 两周没有提交 |
| 🔴 先核对 | star 增长的形状可疑，先人工看一眼 |
